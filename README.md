## アーカイブ済み

`orelia-world` は [orelia-core](https://github.com/orelia-mc/orelia-core) に統合されました。Quest・NPC・Dialogue・Story・Dungeon・CutScene・Event を含む本リポジトリの全機能は、現在 orelia-core 1つのプラグインとして提供されています。

本リポジトリはアーカイブ済み(読み取り専用)です。以後の開発・Issue・PRはすべて [orelia-core](https://github.com/orelia-mc/orelia-core) で行われます。
