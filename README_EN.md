## Archived

`orelia-world` has been merged into [orelia-core](https://github.com/orelia-mc/orelia-core). Every feature this repo used to provide - Quest, NPC, Dialogue, Story, Dungeon, CutScene, Event - now ships as part of the single orelia-core plugin.

This repository is archived (read-only). All further development, issues, and PRs happen at [orelia-core](https://github.com/orelia-mc/orelia-core).
